# Room Calculator MVP

## Название приложения
Room Calculator (Калькулятор помещений)

## Описание
MVP-приложение для расчёта общей площади и тепловой мощности, необходимой для обогрева комнат, квартир и многоэтажных домов. Реализовано с использованием ООП на Python.

## Инструкции по запуску
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите программу: `python main.py`
3. Следуйте инструкциям в консоли для ввода параметров.

## Краткая справка
- Введите название здания.
- Добавьте квартиры и комнаты, указывая их длину, ширину, высоту и уровень утепления.
- Программа рассчитает площадь и тепловую мощность.
- Вы можете сохранить отчёт в формате `.docx`.
